# Ejercicio 03 — Dos LEDs que se alternan (coche fantástico simple)

Dificultad: verde · Módulo 01 (Fundamentos y GPIO digital)

## Enunciado

Dos LEDs que se alternan (coche fantástico simple): uno on mientras el otro off.

## Montaje (Arduino UNO)

Pin 8 -> 220 ohm -> LED A -> GND ; pin 9 -> 220 ohm -> LED B -> GND.

```
UNO pin 8 ──[220Ω]──►|── GND      (LED A)
UNO pin 9 ──[220Ω]──►|── GND      (LED B)
```

## Cómo se resuelve

<!-- EXPLICACION -->
Dos LEDs que se alternan: cuando uno está encendido, el otro está apagado, y viceversa. El montaje es el del ejercicio anterior repetido: cada LED con su resistencia de 220 Ω, uno en el pin 8 y otro en el pin 9, ambos con la vuelta a GND.

Con dos pines en juego, escribir los números a pelo empieza a doler, así que se declaran los dos con nombre:

```cpp
const int LED_A = 8;
const int LED_B = 9;
```

Y en `setup()` hay que configurar **los dos** como salida. Olvidar uno es el fallo típico aquí, y produce un síntoma muy despistante: un LED funciona bien y el otro se comporta de forma errática, lo que hace pensar en un problema de cableado cuando en realidad falta una línea de `pinMode`.

La clave del ejercicio está en el `loop()`. La alternancia no se consigue solo encendiendo, sino **encendiendo uno y apagando el otro en el mismo instante**:

```cpp
digitalWrite(LED_A, HIGH);
digitalWrite(LED_B, LOW);
delay(400);
digitalWrite(LED_A, LOW);
digitalWrite(LED_B, HIGH);
delay(400);
```

Los `digitalWrite` son instantáneos: se ejecutan uno detrás de otro en microsegundos, así que a efectos prácticos el cambio es simultáneo. La espera sí se pone una sola vez por estado, después de haber dejado los dos pines como corresponde. Si pusieras un `delay` entre el encendido de A y el apagado de B, durante ese tiempo los dos estarían encendidos a la vez y perderías la alternancia.

Este es el patrón que necesitarás en el semáforo del siguiente ejercicio: un estado no es "enciendo esto", es "dejo todos los pines como deben estar en este estado".

## Solución — cópiala y ejecútala

```cpp
/*
 * Curso de Arduino — Módulo 01: Fundamentos y GPIO digital
 * Ejercicio 03 — MODELO (resuelto)
 * Enunciado: Dos LEDs que se alternan (coche fantástico simple): uno on mientras el otro off.
 * Dificultad: verde
 * Placa: Arduino UNO
 * Montaje: pin 8 -> 220 ohm -> LED A -> GND ; pin 9 -> 220 ohm -> LED B -> GND.
 */
const int LED_A = 8;
const int LED_B = 9;

void setup() {
    pinMode(LED_A, OUTPUT);
    pinMode(LED_B, OUTPUT);
}

void loop() {
    digitalWrite(LED_A, HIGH);
    digitalWrite(LED_B, LOW);
    delay(400);
    digitalWrite(LED_A, LOW);
    digitalWrite(LED_B, HIGH);
    delay(400);
}
```
