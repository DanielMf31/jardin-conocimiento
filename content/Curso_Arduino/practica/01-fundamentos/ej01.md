# Ejercicio 01 — Parpadear el LED integrado de la placa

Dificultad: verde · Módulo 01 (Fundamentos y GPIO digital)

## Enunciado

Parpadear el LED integrado de la placa (1 s encendido, 1 s apagado).

## Montaje (Arduino UNO)

Ninguno (LED integrado = pin 13 = LED_BUILTIN)

Sin montaje. El LED ya está en la placa (pin 13 / `LED_BUILTIN`).

## Cómo se resuelve

<!-- EXPLICACION -->
El LED que parpadea en este ejercicio ya está soldado en la placa, conectado al pin 13. En el código no se escribe `13` sino `LED_BUILTIN`, un nombre que el propio entorno define por ti: en el UNO vale 13, pero en otras placas el LED está en otro pin, y usando el nombre el mismo sketch funciona en todas.

1. `pinMode(LED_BUILTIN, OUTPUT)` en `setup()` — le dices a la placa que ese pin va a **mandar** corriente, no a leerla. Va en `setup()` porque es una decisión que se toma una vez al arrancar y no cambia.
2. `digitalWrite(LED_BUILTIN, HIGH)` — pone el pin a 5 V. El LED se enciende.
3. `delay(1000)` — la placa se queda quieta 1000 milisegundos, o sea un segundo. Sin esta espera el LED se apagaría inmediatamente después y no verías nada.
4. `digitalWrite(LED_BUILTIN, LOW)` — pone el pin a 0 V. El LED se apaga.
5. `delay(1000)` — el segundo de apagado.

Y al llegar al final de `loop()`, la placa vuelve arriba y repite. De ahí el parpadeo: no hay ningún bucle escrito en el código porque `loop()` **ya es** el bucle.

Lo que más confunde la primera vez es el segundo `delay`. Parece redundante, pero sin él la secuencia sería encender, esperar un segundo, apagar y volver a encender de inmediato. El apagado duraría unos microsegundos, invisibles para el ojo, y verías el LED encendido de forma continua.

## Solución — cópiala y ejecútala

```cpp
/*
 * Curso de Arduino — Módulo 01: Fundamentos y GPIO digital
 * Ejercicio 01 — MODELO (resuelto)
 * Enunciado: Parpadear el LED integrado de la placa (1 s encendido, 1 s apagado).
 * Dificultad: verde
 * Placa: Arduino UNO    Montaje: ninguno (LED integrado = pin 13 = LED_BUILTIN)
 * Correr: Arduino IDE / Wokwi (wokwi/ej01) / arduino-cli (ver README)
 */
void setup() {
    pinMode(LED_BUILTIN, OUTPUT);     // el pin del LED, configurado como SALIDA
}

void loop() {
    digitalWrite(LED_BUILTIN, HIGH);  // 5V -> LED encendido
    delay(1000);                      // esperar 1000 ms = 1 s
    digitalWrite(LED_BUILTIN, LOW);   // 0V -> LED apagado
    delay(1000);
}
```
