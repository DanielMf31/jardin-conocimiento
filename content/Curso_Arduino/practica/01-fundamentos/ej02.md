# Ejercicio 02 — Parpadear un LED EXTERNO en el pin 8

Dificultad: verde · Módulo 01 (Fundamentos y GPIO digital)

## Enunciado

Parpadear un LED EXTERNO en el pin 8 (medio segundo on / medio off).

## Montaje (Arduino UNO)

Pin 8 -> resistencia 220 ohm -> patilla larga del LED (ánodo); patilla corta (cátodo) -> GND.

```
UNO pin 8 ──[ 220Ω ]──►|── GND
                        LED
                 (▲ patilla larga = ánodo hacia la resistencia)
```

## Cómo se resuelve

<!-- EXPLICACION -->
Mismo programa que el anterior, pero ahora el LED no está en la placa: lo pones tú. Eso cambia dos cosas, una en el montaje y otra en el código.

En el **montaje**, la corriente sale del pin 8, atraviesa la resistencia de 220 Ω, atraviesa el LED y vuelve a la placa por GND. Los tres elementos están en serie, así que si falta cualquiera de ellos no circula nada. La resistencia no es un adorno: un LED conectado directo entre el pin y masa deja pasar toda la corriente que puede, y eso lo destruye a él y castiga al pin. Y el LED tiene polaridad: la patilla larga (ánodo) va hacia la resistencia, la corta (cátodo) a GND. Al revés no se rompe, simplemente no enciende.

En el **código**, aparece la primera buena costumbre del curso:

```cpp
const int LED = 8;
```

En vez de escribir `8` en cada `digitalWrite`, se le da nombre una vez. `const` significa que ese valor no va a cambiar durante la ejecución, y el compilador lo hace cumplir. La ventaja se nota el día que mueves el LED de sitio: cambias una línea en vez de buscar todos los `8` del fichero y acertar cuáles eran el número de pin y cuáles otra cosa.

El resto es idéntico al ejercicio anterior, con `delay(500)` en vez de `delay(1000)`: medio segundo encendido y medio apagado, el doble de rápido. Prueba a bajarlo a 50 y verás que el parpadeo deja de percibirse como parpadeo.

## Solución — cópiala y ejecútala

```cpp
/*
 * Curso de Arduino — Módulo 01: Fundamentos y GPIO digital
 * Ejercicio 02 — MODELO (resuelto)
 * Enunciado: Parpadear un LED EXTERNO en el pin 8 (medio segundo on / medio off).
 * Dificultad: verde
 * Placa: Arduino UNO
 * Montaje: pin 8 -> resistencia 220 ohm -> patilla larga del LED (ánodo);
 *          patilla corta (cátodo) -> GND.
 */
const int LED = 8;            // damos nombre al pin para no repetir el número

void setup() {
    pinMode(LED, OUTPUT);
}

void loop() {
    digitalWrite(LED, HIGH);
    delay(500);
    digitalWrite(LED, LOW);
    delay(500);
}
```
