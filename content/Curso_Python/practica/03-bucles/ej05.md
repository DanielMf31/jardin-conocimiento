# Ejercicio 05 — Pide N e imprime todos los primos entre 2 y N

Dificultad: amarillo · Módulo 03 (Bucles)

## Enunciado

Pide N e imprime todos los primos entre 2 y N

## Cómo se resuelve

<!-- EXPLICACION -->
Listar los primos hasta N combina dos bucles anidados con `break` y estrena una joya de Python: el `else` del `for`.

1. `for p in range(2, n + 1)` — el bucle exterior recorre cada candidato `p` que podría ser primo.
2. `for d in range(2, int(p**0.5) + 1)` — el bucle interior busca un divisor de `p`. Solo probamos hasta la raíz cuadrada (`p**0.5`) porque si `p` tiene un divisor mayor que su raíz, forzosamente tiene otro menor que ya habríamos encontrado; esto ahorra muchísimas vueltas.
3. `if p % d == 0: break` — si `d` divide a `p` (resto cero), `p` no es primo y cortamos el bucle interior con `break`: no tiene sentido seguir buscando más divisores.
4. `else:` colgado del `for` (no del `if`) — este `else` se ejecuta solo si el bucle interior terminó SIN toparse con un `break`, es decir, si no encontró ningún divisor. En ese caso `p` es primo y lo imprimimos.

El `for ... else` no existe en C; allí necesitarías una bandera (`bool es_primo = true;`) que pones a `false` al hallar un divisor y consultas después del bucle. Python te da esa lógica de "el bucle terminó limpio" de forma directa.

Trampa habitual: creer que el `else` va con el `if`. Fíjate en la indentación: está alineado con el `for` interior, y su regla es "si no hubo `break`".

## Solución — cópiala y ejecútala

```python
# Curso de Python — Modulo 03: Bucles
# Ejercicio 05 — MODELO (resuelto)
# Enunciado: Pide N e imprime todos los primos entre 2 y N
# Dificultad: amarillo
# Ejecutar: python3 ej05_modelo.py

n = int(input("Hasta que numero buscar primos: "))

for p in range(2, n + 1):
    # Comprueba si algun numero entre 2 y sqrt(p) divide a p
    for d in range(2, int(p**0.5) + 1):
        if p % d == 0:
            break  # encontramos un divisor: p no es primo
    else:
        # El for termino sin break => ningun divisor => p es primo
        print(p)
```
