# Ejercicio 02 — Devuelve True si algun valor aparece al menos dos veces en nums

Dificultad: verde · Módulo 09 (Puente a NeetCode)

## Enunciado

devuelve True si algun valor aparece al menos dos veces en nums

## Cómo se resuelve

<!-- EXPLICACION -->
Detectar duplicados es el ejemplo más limpio del patrón "set de elementos ya vistos": convertir una búsqueda repetida en una consulta O(1).

1. `vistos = set()` — un conjunto vacío. La pertenencia (`in`) en un set es O(1) porque usa tabla hash, igual que un dict pero sin valores asociados.
2. En `for n in nums` recorremos una vez. `if n in vistos: return True` corta en cuanto encontramos algo repetido, sin seguir mirando el resto.
3. `vistos.add(n)` registra el número actual. Recorrer + consultar da O(n) tiempo y O(n) espacio, frente a los O(n^2) de comparar cada elemento con todos los demás.
4. La versión bonus `len(nums) != len(set(nums))` explota que un set descarta duplicados al construirse: si el conjunto encoge, es que había repetidos. Es elegante, pero siempre recorre la lista entera; la versión explícita puede salir antes.

Trampa habitual: pensar que ordenar primero y comparar vecinos es igual de bueno. Ordenar cuesta O(n log n), peor que el O(n) del set, y además modifica el orden. El set gana en tiempo a cambio de memoria.

## Solución — cópiala y ejecútala

```python
# Curso de Python — Modulo 09: Puente a NeetCode
# Ejercicio 02 — MODELO (resuelto)
# Enunciado: devuelve True si algun valor aparece al menos dos veces en nums
# Dificultad: verde
# Ejecutar: python3 ej02_modelo.py

# PATRON: set como coleccion de elementos ya vistos.
# Un set no guarda duplicados; si intentas insertar uno que ya existe,
# el set no cambia. Aprovechamos eso: comprueba antes de insertar.
# Coste: O(n) tiempo, O(n) espacio.
#
# Alternativa ultracorta: len(nums) != len(set(nums))
# La mostramos como bonus despues de la version explicita.


def contains_duplicate(nums: list) -> bool:
    """Devuelve True si hay algun duplicado en nums."""
    vistos = set()

    for n in nums:
        if n in vistos:
            return True   # duplicado encontrado
        vistos.add(n)

    return False


def contains_duplicate_bonus(nums: list) -> bool:
    """Version compacta: si el set es mas pequeno, hubo duplicados."""
    return len(nums) != len(set(nums))


# --- Pruebas manuales ---
if __name__ == "__main__":
    casos = [
        ([1, 2, 3, 1], True),
        ([1, 2, 3, 4], False),
        ([1, 1, 1, 3, 3, 4, 3, 2, 4, 2], True),
    ]

    for nums, esperado in casos:
        r1 = contains_duplicate(nums)
        r2 = contains_duplicate_bonus(nums)
        e1 = "OK" if r1 == esperado else "FALLO"
        e2 = "OK" if r2 == esperado else "FALLO"
        print(f"[{e1}] explicita: {r1}   [{e2}] bonus: {r2}   nums={nums}")
```
