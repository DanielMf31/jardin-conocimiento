# Ejercicio 02 — Pide dos enteros e indica cual es mayor, o si son iguales

Dificultad: verde · Módulo 02 (Condicionales)

## Enunciado

Pide dos enteros e indica cual es mayor, o si son iguales

## Cómo se resuelve

<!-- EXPLICACION -->
Comparar dos números tiene tres desenlaces posibles, y con `if/elif/else` cubrimos los tres sin que se solapen.

1. `a = int(input(...))` y su gemelo para `b` — leemos los dos enteros convirtiendo el texto con `int()`.
2. `if a > b:` — primera pregunta. Si es cierta, `a` es el mayor y ya no se evalúa nada más de la cadena.
3. `elif b > a:` — el `elif` (else if) solo se comprueba si el `if` anterior falló. Llegar aquí significa que `a` no era mayor, así que preguntamos si lo es `b`.
4. `else:` — si ni `a > b` ni `b > a`, la única posibilidad que queda es que sean iguales; por eso no necesita condición propia. Encadenar `if/elif/else` garantiza que se ejecute exactamente una rama.

Trampa habitual: usar tres `if` sueltos en vez de `elif`. Con `if` independientes Python evalúa las tres condiciones siempre, y aunque aquí darían el mismo resultado, en casos con solapamiento podrías imprimir dos mensajes. El `elif` corta en cuanto una se cumple.

```python
# Curso de Python — Modulo 02: Condicionales
# Ejercicio 02 — MODELO (resuelto)
# Enunciado: Pide dos enteros e indica cual es mayor, o si son iguales
# Dificultad: verde
# Ejecutar: python3 ej02_modelo.py

a = int(input("Introduce a: "))
b = int(input("Introduce b: "))

if a > b:
    print(f"El mayor es {a}")
elif b > a:
    print(f"El mayor es {b}")
else:
    print("Son iguales")
```
