# Ejercicio 01 — Lee una palabra e imprimela al reves usando slicing

Dificultad: verde · Módulo 06 (Cadenas)

## Enunciado

Lee una palabra e imprimela al reves usando slicing

## Cómo se resuelve

<!-- EXPLICACION -->
Invertir una palabra en Python no necesita ni bucle ni variable auxiliar: el slicing lo hace en un solo paso, y ahí está la lección.

1. `palabra = input("Introduce una palabra: ")` — leemos el texto tal cual; no hace falta convertirlo porque ya queremos trabajar con la cadena.
2. `palabra[::-1]` — el slicing tiene la forma `[inicio:fin:paso]`. Al dejar `inicio` y `fin` vacíos y poner `paso = -1`, Python recorre la cadena desde el último carácter hasta el primero.
3. El resultado se guarda en `invertida` porque el slicing NO modifica `palabra`: en Python las cadenas son inmutables, así que cada operación de este tipo devuelve una cadena nueva y deja la original intacta.
4. `print(invertida)` — mostramos la copia ya dada la vuelta.

Trampa habitual: en C invertirías el `char[]` in situ intercambiando extremos con un bucle, porque la cadena se puede modificar carácter a carácter. En Python eso daría error (`s[i] = ...` no está permitido); por eso el idioma es crear una cadena nueva con `[::-1]`.

## Solución — cópiala y ejecútala

```python
# Curso de Python — Modulo 06: Cadenas: transformar y formatear
# Ejercicio 01 — MODELO (resuelto)
# Enunciado: Lee una palabra e imprimela al reves usando slicing
# Dificultad: verde
# Ejecutar: python3 ej01_modelo.py

palabra = input("Introduce una palabra: ")

# El slicing [::-1] recorre el string de atras hacia adelante (paso -1)
# y devuelve un string nuevo, porque str es inmutable
invertida = palabra[::-1]

print(invertida)
```
