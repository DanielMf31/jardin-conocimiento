## Cómo se resuelve

<!-- EXPLICACION -->
Aquí escribes **dos funciones pequeñas**, `max(a, b)` y `min(a, b)`, cada una con su prototipo arriba. Cada una recibe dos enteros y devuelve uno solo.

- `max` compara: si `a > b`, `return a;` corta ahí mismo y sale de la función; si no llega a ese `return`, ejecuta `return b;`. No hace falta `else`, porque un `return` termina la función de inmediato.
- `min` es la misma idea con el operador al revés.
- En `main` lees dos enteros con `scanf("%d %d", &x, &y)` (los enteros **sí llevan `&`**, porque `scanf` necesita la dirección donde guardar) y pasas `x` e `y` a cada función.

El concepto clave es que `x` e `y` viajan **por valor**: dentro de `max`, los parámetros `a` y `b` son copias. La función devuelve un dato nuevo; no modifica tus variables originales.

Trampa típica: intentar que una sola función devuelva "el mayor y el menor a la vez". Una función con `return` normal devuelve **un único valor**. Para dos resultados, lo natural aquí son dos funciones separadas (más adelante verás cómo devolver varios valores con punteros).

## Solución — cópiala y ejecútala

```c
/*
 * Curso de C — Modulo 04: Funciones
 * Ejercicio 02 — MODELO (resuelto)
 * Enunciado: Funciones max(a,b) y min(a,b). Pide dos enteros e imprime el mayor y el menor.
 * Dificultad: verde
 * Compilar: gcc -std=c11 -Wall ej02_modelo.c -o ej02 && ./ej02
 */

#include <stdio.h>

/* Prototipos */
int max(int a, int b);
int min(int a, int b);

int main(void) {
    int x, y;
    printf("Introduce dos enteros: ");
    scanf("%d %d", &x, &y);
    printf("Max: %d\n", max(x, y));
    printf("Min: %d\n", min(x, y));
    return 0;
}

/* Devuelve el mayor de a y b */
int max(int a, int b) {
    if (a > b) return a;
    return b;
}

/* Devuelve el menor de a y b */
int min(int a, int b) {
    if (a < b) return a;
    return b;
}
```
